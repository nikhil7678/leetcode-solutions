# Problem: Reverse a String (Easy)

Link: https://leetcode.com/problems/reverse-string/

## Approach

I used two pointers, one at the beginning and one at the end of the string. I swapped the characters and moved both pointers towards the center until the string was reversed.

## Complexity

Time: O(n)
Space: O(1)

## Notes

Tested the program with two test cases. The first reverses the word "hello" and the second checks a single-character string.
